# hucolor 配色参考

> 暖纸 + 靛蓝 + 陶土橙

hucolor (1.0.2) 是一套低饱和、暖底、冷主色的配色体系，围绕「靛蓝主色 + 兰花紫 + 暖橙点缀」展开。暗色为默认变体，亮色为暖纸风格。本文档定义色彩角色、色值、语义映射与使用原则，供网页、终端与编辑器参考。

## 1. 设计语言

- **底色**：暗色为「微紫深灰」，亮色为「暖纸」（`#f7f7f5`）。
- **主色**：靛蓝（偏紫的蓝）用于一切"动作/结构"；暖橙只做点缀，不喧宾夺主。
- **语义统一**：同一语义在不同介质（网页 / 终端 / 编辑器）中取同一组色值，跨介质观感一致。
- **层级分明**：背景分三档（`bg0 / bg1 / bg2`）、文字分四档（`strong / text / muted / faint`），通过层级而非颜色表达主次。
- **定义与应用**：暗色背景以「定义值」为设计基准，终端 / 编辑器等场景使用「提亮应用值」（`bg0` 提亮值即终端默认背景）。文字、强调、语义色两种场景一致，不提亮。

## 5. 派生色与取色规则

- **红**：暗色与暖橙解耦，独立取值 `#e0554a`（暖红，hue ≈ 4°），与暗色暖橙 `#f0a35e`、亮色暖橙 `#d9582e` 均明显区分；亮色下暖橙已占用 `#d9582e`，红另取 `#c94b3d`（更深更暖的陶土红）以免混淆。
- **青**：色板缺青色相，暗青 `#7cc6cf` 取低饱和、与靛蓝同冷色族；亮青 `#2f9eab` 为对应亮色版。
- **靛蓝强档**：`blue_bright`（`accent-strong`）须与主色 `blue` 拉开对比——暗色明显提亮（`#d6d7ff`）、亮色明显加深（`#2f3fae`），避免二者混同。
- **混色规则**：需要"底色 + 色"的场景按固定比例混色，例如标题背景 = `bg0` 与标题色 10:1 混色。当前暗色应用值：`Headline1`→`#362f2d`、`Headline2`→`#352f2a`、`Headline3`→`#27322e`、`Headline4`→`#2f2f3c`、`Headline5`→`#322d3a`、`Headline6`→`#33333c`。

## 6. 使用原则

- **背景**：`bg0` 为编辑器 / 正文底；`bg1` 用于卡片、浮窗、侧栏、cursorline；`bg2` 用于 hover、偶数行、折叠区。不可倒挂（浅色不用于更底层级）。
- **文字**：`fg0` 标题 / 强调，`fg1` 正文，`fg2` 注释与次要，`fg3` 行号 / 页脚 / 占位。等级只做明暗区分，不引入色相。
- **强调**：主强调只用 `blue`；`green` / `yellow` 仅表"成功 / 警告"语义，不当作装饰色替代主色。
- **误差范围**：同语义值在不同实现间允许 `±1`，视为一致。
